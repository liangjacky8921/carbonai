## 当前判断

分类为 **F：暂时无法复现**。从正常与无痕 PC Chrome 均可渲染、手机可打开的证据看，故障可能限定于原有 PC 浏览器配置或旧标签页；这是推测，尚无该浏览器控制台和 Network 记录支持。首页是否在用户电脑上因 WebGL、扩展、缓存或显卡驱动卡住，仍未确认。

## 下一步最小取证与恢复

1. 在受影响的 PC 上新开无痕窗口访问 `https://www.carbontool.cn/`。若能打开，关闭旧标签页并在正常窗口按 `Ctrl+Shift+R` 强制刷新；这不会清空其他网站数据。
2. 若正常窗口仍失败，打开 DevTools 的 Console 与 Network，启用 Preserve log，重新加载一次，保存首个阻断错误、失败请求 URL/状态及页面截图；同时记录 Chrome 版本、是否启用扩展、具体是空白/卡住/证书提示/无法连接。只清理本网站数据应在证据指向缓存后再考虑。
3. 若无痕也失败，在同一电脑分别打开 `www` 和非 `www` 地址，记录最终地址、错误代码及网络类型；再核对该电脑的 DNS、代理、证书与显卡/WebGL 状态。
