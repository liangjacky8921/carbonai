# CarbonAI V5.2 — 软件著作权登记全流程指南（2026 联网核实版）

> 信息来源：中国版权保护中心官网（ccopyright.com.cn，2026-09 检索核实）+ 北京市投资促进服务中心公开问答。
> 本文档与《软著申请指南.md》《软件设计说明书-模板.md》配合使用，构成完整申请材料包。

## 一、登记机构与官方口径

- **登记机构**：中国版权保护中心（CPCC），国家版权局认定的软件登记机构
- **官网**：https://www.ccopyright.com.cn （登记办理系统：register.ccopyright.com.cn）
- **咨询电话**：010-61090099

## 二、全过程流程（六步）

```
账号注册 → 实名认证 → 填报提交 → 登记机构受理 → 登记机构审查 → 取得登记证书
```

1. **账号注册**：官网注册个人账号（自然人与法人分别注册）。
2. **实名认证**：办理前按指引完成实名认证（自然人：身份证 + 人脸识别；免费）。
3. **填报提交**：选择「计算机软件著作权登记」，在线填报申请表，上传申请材料，确认无误后提交。
4. **登记机构受理**：材料符合要求即受理；材料不齐或存在问题的，**30 日内**按要求补正，逾期视为撤回。
5. **登记机构审查**：**自受理日起 60 日内**审查完成；符合《计算机软件保护条例》和《计算机软件著作权登记办法》规定的予以登记。
6. **取得证书**：登记完成后官网发布公告，申请人可在用户中心下载**电子证书**（PDF 格式，带「计算机软件著作权登记专用章」电子签章，支持在线/本地验签）。

## 三、申请材料（三件套）

### 1. 软件著作权登记申请表
在线填报 → 在线打印申请确认签章页（勿改格式）→ 签章 → 扫描 PDF 上传。
关键信息：软件全称/简称、版本号（V5.2）、开发完成日期、首次发表日期、权利取得方式（原始取得）、权利范围。

### 2. 软件的鉴别材料（源程序 + 文档）
- **一般交存**：源程序和文档**前后各连续 30 页**（共 60 页）；不足 60 页的提交全部。
- 程序每页 **不少于 50 行**，文档每页不少于 30 行；页眉标注软件名称+版本号+页码。
- 本仓库对应材料：
  - 源代码前端 30 页 → `frontend/src/`（views / components / stores / utils）
  - 源代码后端 30 页 → `backend/app/`（routers / schemas / db / main）
  - 文档 60 页 → 《软件设计说明书-模板.md》按 V5.2 新界面截图填充

### 3. 身份证明文件
- 自然人：身份证正反面扫描件
- 法人：营业执照副本（加载统一社会信用代码）扫描件
- 委托/合作/职务开发：另附委托开发合同 / 合作开发合同 / 任务书等权利归属证明
