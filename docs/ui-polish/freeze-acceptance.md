## 浏览器验收

环境：本机 Vite 构建预览 `http://127.0.0.1:4175/`，Codex 内置浏览器的 Playwright 操作与 DOM/视觉检查。视口分别设为 1440×900、1280×800、390×844；这只是浏览器视口模拟。

### 通过

- 三个视口均可渲染首页；H1 保持“看清排放 / 理解空间 / 让决策有据”三行。UI-1 的“数据路径、空间视角、产品界面、进入平台”章节标记与标题断行正常，`<br>` 结构保留。GIS 与数据大厅预览均标注“示例数据”，GIS 说明为“GIS 工作台界面预览”。
- 1440 与 1280 桌面首屏可见 3D 地球 Canvas、标题、CTA 和导航，无遮挡；390 手机视口目录可展开，点击“数据路径”后菜单关闭并跳转对应章节。三个视口未发现文档级横向溢出。
- 桌面滚动依次触发数据路径、空间视角、产品界面和结尾章节显现；六个章节均存在，结尾 CTA 正常显示。当前首页使用 CSS 与 `IntersectionObserver`，未发现首页 GSAP/ScrollTrigger 调用，因此不将其记为“GSAP 运行通过”。
- UI-2 提升的局部信息字号在桌面显示为 11–12px，390 视口标题与说明未溢出；GIS 与产品截图外框均保持原有直角，未改动圆角变量。`MainLayout.vue` 顶栏边框源码已从 `0.5px` 调为 `1px`，本机浏览器计算值为 `0.8px`，可见分割线正常。
- 数据大厅、GIS、登录、碳核算四个路由在 390 视口均渲染标题与内容、无页面横向溢出。数据大厅与 GIS 保留“示例数据”标记。上述页面及首页检查期间未见 Console `error`。
- 键盘 Tab 可聚焦首页“核算模块”链接，`:focus-visible` 生效，显示实线焦点轮廓。源码中首页、地球及相关章节保留 `prefers-reduced-motion` 分支。

### 失败

- 本轮范围内未发现明确回归缺陷，因此未执行修复。

### 未验证与限制

- 当前浏览器仅提供视口切换，未提供 `prefers-reduced-motion` 媒体偏好模拟；减少动画的运行时行为只做静态检查。
- 390×844 模拟不等同真实 iOS Safari；真实设备触控、字体渲染与 GPU 表现待人工验证。
- 本地预览的数据大厅显示“离线”和内置示例数据；本轮未验证生产 API、登录提交、GIS 查询或碳核算计算结果。
- 地球 Canvas 已显示，但未做 GPU 性能、WebGL 失败降级或长期资源释放测试；这些不属于 UI-1/UI-2 的改动。

UI-1/UI-2 局部视觉回归检查通过，可提交给项目负责人确认是否冻结 V6.0。冻结前如要求覆盖真实手机或减少动画运行态，应另行补测；本报告不等于生产环境验收。
