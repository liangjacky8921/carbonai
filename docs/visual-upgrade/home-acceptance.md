# CarbonAI 首页 H5 性能与质量验收

> 验收日期：2026-10-13
> 对象：本地生产构建预览
> 结论：通过本阶段可执行验收；保留公网指标、真实 WebGL 禁用环境和联系方式核验三项发布前事项。

## 1. 构建结果

- 命令：`npm run build`
- 结果：通过，Vue 类型检查与 Vite 生产构建均成功。
- 转换模块：2,981。
- 首页路由 JS：22.91 KB，gzip 9.47 KB。
- 首页路由 CSS：25.23 KB，gzip 5.60 KB。
- 3D 地球按需块：130.51 KB gzip。
- 地理点数据按需块：50.11 KB gzip。
- 全局 Element Plus 块：372.80 KB gzip。
- 全局 ECharts 块：511.49 KB gzip。

3D 地球及点位数据通过动态导入加载，并在手机端和 reduced-motion 条件下使用静态 SVG，未并入首页同步路由块。

## 2. 响应式验收

| 视口 | 导航 | 地球 | 横向溢出 | 结果 |
| --- | --- | --- | --- | --- |
| 1440 × 1000 | 完整桌面导航 | 1 个 Canvas，916 × 653 | 无 | 通过 |
| 1280 × 900 | 完整桌面导航 | 1 个 Canvas，814 × 653 | 无 | 通过 |
| 768 × 900 | 折叠目录 | 1 个 Canvas，532 × 653 | 无 | 通过 |
| 390 × 844 | 折叠目录 | 静态 SVG，Canvas 为 0 | 无 | 通过 |

首次检查发现 768px 顶部导航被压缩为多行。本阶段将折叠目录断点调整为 900px，复测后品牌、目录和工作台入口保持单行且可操作。

## 3. 交互与生命周期

| 项目 | 结果 |
| --- | --- |
| 暂停背景动效 | 按钮 `aria-pressed` 切换为 `true`，文案切换为“播放背景动效” |
| 进入工作台 | 路由进入 `/dashboard`，首页与 3D Canvas 均卸载 |
| 返回首页 | 首页恢复且仅创建 1 个 Canvas，没有重复实例 |
| 手机降级 | 390px 不初始化 WebGL，静态地球正常显示 |
| reduced-motion | H3 已在真实媒体偏好下验证：Canvas 为 0、章节直接显示、平滑滚动关闭 |
| 控制台 | 四视口和路由往返检查均为 0 个错误 |

组件源码同时包含页面隐藏暂停、IntersectionObserver 离屏暂停、WebGL 上下文丢失回退、ResizeObserver 断开、动画帧取消、材质与几何体释放以及 renderer context 释放逻辑。

## 4. 本地加载数据

本地生产预览连续 5 次 HTML 请求：

- TTFB：3.53–6.07 ms，中位数约 3.82 ms。
- 总请求时间：3.58–6.13 ms。

这些数据只反映本机回环网络和已构建静态文件，不能代表公网用户体验。

## 5. 未测项目

- LCP、CLS、INP：当前内置浏览器未暴露 Performance Timeline，未记录数值。
- 长时间 FPS、CPU 和 GPU 内存：当前工具无法形成可靠、可复现的采样，未测。
- 页面真正进入后台再恢复：当前自动化环境无法切换标签页可见状态，未做运行时实测。
- WebGL 被浏览器完全禁用：当前环境无法启动禁用 WebGL 的独立浏览器；已验证手机静态路径并检查失败回退代码。
- 公网生产性能：本阶段未部署，因此未测。

## 6. 发布前事项

1. 部署预览环境后，用 Lighthouse 或 Chrome Performance 在真实网络条件下记录 LCP、CLS、INP 和长任务。
2. 站点主体已确认唯一备案信息为“粤ICP备2026140571号”；是否提供公开联系方式仍待决定。
3. Element Plus 与 ECharts 共享块较大，但属于多个业务路由共用依赖；若继续优化，应单独评估按需导入，避免在本阶段扩大改动范围。
4. 部署前再次执行生产构建，并对首页、工作台、GIS 和登录路由做冒烟检查。
