# CarbonAI 任务二 T2-1：数据大厅现状审查

状态：**审查完成，待执行改造**（2026-10-16）。本轮仅阅读当前仓库中的相关实现；未运行浏览器、构建或接口请求，因此布局问题是代码风险，线上数据可用性尚未实测。开始审查时 Git 工作区无改动。

## 页面与现有能力

- 路由 `/dashboard` 使用 `MainLayout.vue`，目前无需登录即可访问；左侧模块导航、顶栏连接状态和全局“示例数据/用户数据”操作由布局提供。页面主体在 `DashboardView.vue`，最大宽度 1600px。
- 自上而下为：碳行情跑马灯及暂停按钮；总排放、Scope 1/2/3 四张 KPI；六张 ECharts 图；“异常指标与洞察”。图表依次为碳价/指数折线、所谓区域碳市场“占比”环图、湾区 11 城 3D 柱图、排放源 Top8 环图、Scope 环图、年度趋势叠加折线。
- 大厅本身**没有年份、企业、地区或日期筛选器**。年份取 `dataStore.currentYear`，首次加载若不在数据年份内则选最新年份。可暂停行情、点 3D 城市柱查看详情、查看图表提示；布局顶栏的“切回示例”会清除浏览器本地用户数据，属于全局操作而非大厅筛选。

- `components/ChartCard.vue` 已支持标题、加载骨架、空状态、示例/用户数据徽标；大厅只传了 `loading`，尚未使用其来源和空状态能力。
- `components/MotionNumber.vue`、`utils/chartTheme.ts`、`styles/theme.css` 中的卡片、数字、徽标样式和 `composables/useElementResize.ts` 可继续复用。图表容器已有 `ResizeObserver`，卸载时会释放 ECharts 实例。
- 图表库为 `echarts` 5.5 系列与 `echarts-gl` 2.0 系列；页面以 `import * as echarts` 加载并创建六个实例。没有在大厅引入另一套图表库。

## 待处理问题（按优先级）

1. **P0 数据语义：**“区域碳市场占比”环图把各市场的**价格**当成份额求百分比，前后端快照均如此；该百分比没有有效统计意义。后续应在取得同口径交易量/成交额前停用“占比”表达，或改成清楚标价的价格对比图。见 `DashboardView.vue:41,204`、`data/carbonMarket.ts` 的 `MARKET_SHARE`、`backend/app/routers/business.py` 的 `_MARKET_SNAPSHOT`。
2. **P1 来源与时效：**离线静态行情仍以本机当前时间显示“更新”；后端时间戳也是接口生成时间，不等于各项行情发布时间。后端实源/回退说明未呈现。另 `backendOnline` 探测是异步触发，大厅只在挂载时检查一次，可能错过后端行情请求。见 `DashboardView.vue:120–125,342–359`、`main.ts:28–33`。
3. **P1 数据一致性：**上传记录持久化到 `localStorage`，`source.emissions` 却每次启动默认 `sample`；刷新后可能重新展示示例。KPI 是响应式计算，但六张图仅在挂载时绘制；在大厅内切换/重置数据后，图表可能仍显示旧值。见 `stores/data.ts:55–65,138–143`、`DashboardView.vue:325–359`。
4. **P1 安全与事实表述：**“洞察”通过 `v-html` 渲染包含上传记录 `source` 字段的字符串，若上传内容带 HTML，存在注入风险；营收与配额常量应标注为示例假设或改由经核实数据驱动。见 `DashboardView.vue:91,138–155`。
5. **P1/P2 可读性与操作：**六图未使用 `ChartCard` 的示例/用户徽标与 `empty`；无数据时 0 值和空图缺少明确说明。3D 城市图只提供图形点击路径，没有等效键盘城市列表；`viewControl.autoRotate` 不随减少动画偏好关闭。
6. **P2 桌面/手机布局风险：**桌面两列与 7:5、4:8 网格依赖固定 280–360px 图高；窄屏改为单列后，3D 轴标签、Top8 侧边图例及 236px 城市浮层可能挤占图面。行情右侧绝对定位的时间/暂停控件可能遮住滚动内容；20px 浮层关闭键与 28px 高暂停键触控区域偏小。需在 1440px、390px 浏览器中确认具体遮挡，不能视作已复现。

## 后续最小改动建议（待下一任务批准范围后执行）

1. 先纠正区域“占比”图语义，给静态/实源行情及城市示例、用户排放数据明确标签与日期；不要把请求时间当作数据更新时间。
2. 让来源模式在刷新后与已保存的用户记录一致；给六图接入 `ChartCard` 来源/空状态，并在数据源或年份变化时更新对应图表。
3. 将洞察改为安全的文本/结构化模板；把营收、配额假设明示或从可核实输入取得。
4. 只对确认的问题调整小屏图例、浮层、按钮尺寸和 3D 动画偏好，补充可键盘操作的城市选择入口；再以桌面/手机局部浏览器验收。
