## 元信息使用约定

- `sample` 表示内置示例；`userTag` 表示用户上传，**不代表已认证的真实监测数据**。两者互斥使用。
- `sourceNote` 只填可核实的数据来源；`updatedAt` 只填记录或来源提供的时间，不使用页面打开时间或接口响应时间冒充数据更新时间。
- `ChartCard` 新属性为可选。现有页面没有可靠时间字段时保持缺省；页面级业务文案需待来源与授权核实后再改。

## 遗留与限制

- `SewageView.vue` 与 `SoilView.vue` 当前把“真实运行/实验数据（平台内置）”放入 `.sample-badge`，数据真实性、授权及更新时间尚需逐项核实；本轮未改业务文案或标签含义。
- 各页面的来源字段和时间字段并不一致。要让所有卡片显示具体来源与更新日期，须在后续逐页核实字段后传入 `ChartCard`，不能从共享组件推断。
- 表格排序、筛选、上传反馈和各页面窄屏内容属于业务页面行为；本轮只统一共享样式，没有宣称完成逐页交互验收。
