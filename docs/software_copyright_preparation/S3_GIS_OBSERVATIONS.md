# S3 — 遥感观测 GIS 图层（本地）

日期：2026-10-19。S2 后端保持默认关闭；本阶段仅新增前端展示与查询，不部署、不修改原有碳核算、数据库或 GIS 底图业务。

## 检查与改动

- 复核 `S2_BACKEND_INTEGRATION.md` 的列表和详情契约，及 `frontend/src/views/GisView.vue` 中的 Leaflet 地图、高德底图、现有图层和生命周期。
- `frontend/src/api/carbonMapper.ts`：沿用现有 HTTP 客户端调用列表/详情接口；为高德 GCJ-02 地图与官方 WGS84 观测坐标增加前端显示/视野边界转换。无示例数据回退。
- `frontend/src/components/gis/RemoteObservationPanel.vue`：增加默认关闭的图层开关、CH₄/CO₂ 和观测日期筛选、当前地图范围查询、键盘可操作的记录选择，以及观测详情、来源与服务状态。
- `frontend/src/views/GisView.vue`：复用 Leaflet，增加独立图层及点击选中；移动、筛选、关闭图层或离开页面时取消请求并清除观测标记。原有林地、碳源和 GBA 图层保留。

## 技术决策

- 仅展示离散、已发布羽流观测；排放率为 null 时显示“暂无数据”，质量为 null 时显示“未知（不可视为合格）”。不推算年排放、不自动归因企业、不宣称连续实时监测。
- 地图标记为点位符号，不画扩散范围；详情保留官方 WGS84 坐标。查询最多 100 条，超过上限时不声称已覆盖全部记录。
- 后端关闭、限流、无数据和请求失败分别反馈；请求失败时不切换至演示数据。前端不保存 API Token 或观测缓存。
