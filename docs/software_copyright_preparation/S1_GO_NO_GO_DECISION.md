# S1 Go / No-Go 决策

日期：2026-10-19；S1.5 补充后结论仍为 **CONDITIONAL GO**。符合官方默认许可条件的非商业展示/再分发并非一律需要另行书面授权，但 CarbonAI 的运营事实、署名与同条件传递方式尚未确认；公开接入与上线暂缓。详见 `S1_5_SUPPLEMENTARY_VALIDATION.md`。

## 判据

| 维度 | 实际证据 | 结论 |
| --- | --- | --- |
| 技术可达 | 无令牌 `GET /api/v1/catalog/plumes/annotated` 对粤港澳、中国 CH₄ 和卡塔尔 CO₂ 三个小框均 HTTP 200；按 BBOX/日期过滤和分页；见 `S1_REAL_DATA_VALIDATION.md`。 | 技术可行，不能据此认定生产集成获准。 |
| 目标区数据 | S1.5 `limit=100` 返回 64 个区域内 `items`；45 个非空且未隐藏的排放率、19 个 null。64 条 `plume_quality` 全为 null；`qualities=good` 过滤得到 19 条但其响应质量字段仍为空。 | 独立观测点展示有数据基础；不能称 45 条均完成质量确认，不能据此做完整定量分析或企业归因。 |
| 许可 | [2026-01-13 Terms](https://carbonmapper.org/terms) §3.1 允许符合条件的展示和分发，§3.2–3.4 限非商业、目的、署名及同条件再分发；[数据页](https://carbonmapper.org/data)指引集成注册。CarbonAI 运营/收费/下载场景未核实。 | 并非因缺单独书面授权就禁止非商业演示；但实际条件需负责人确认，API 正式接入方式需核实。 |
| 数据语义 | [产品指南](https://carbonmapper.org/articles/product-guide)将 scene/plume/source、观测与发布日期及 L2C/L4 区分；实测字段有 null/隐藏。 | 可设计独立观测图层；不得称实时、随意补值、将 plume 直接归给企业或写入碳核算。 |

## 当前允许与禁止

- **允许**：保留最小内部样例，继续核对运营用途与正式 API 接入方式；可在隔离本地环境设计空状态、类型与 UI，不公开分发数据。
- **暂不做**：自动进入 S2 真实集成、公开网站接入、把外部点位落生产库、开放下载/长期缓存、使用 Carbon Mapper 品牌图像。
- **进入 S2 真实接入的条件**：负责人确认非商业运营、未来收费计划、明确署名与 Share-Alike 传递方式；核实 API 注册/配额；明确质量筛选与响应字段不一致时的显示策略及高德底图坐标验证。符合默认许可条件即可继续，无须一概要求单独书面授权；若拟商业使用或条款适用有争议，再与权利方确认。若许可不成立，则转 **NO-GO**；只保留未接入占位或使用确有授权的数据。

## 本阶段交付与检查

- 实际修改：只新增四份 S1 报告及一个最小 JSON 样例；未修改业务源码、数据库、部署配置，未提交、推送或部署。
- 请求与结果：官方文档和 OpenAPI GET；数据 API 三个区域各 `limit=2` 和 `limit=1`，共 6 次无令牌 GET，均 HTTP 200；最小字段记录见样例。未尝试认证、下载、全量分页或压力测试。无代码改动，故未执行构建；此前 S0 类型/定向测试结果不能替代 S1 API 权限验收。
- 风险：许可/商业性质、再分发、缓存期限、部分数值隐藏、质量为空、坐标底图误差、非连续覆盖及企业误归因。下一阶段：**等待上述条件审核，不自动开始 S2**。

S1.5 补充检查：一次 `limit=100` 完整取回 64 条；另两次 `qualities=good` 小查询验证过滤/字段不一致。详见 `S1_5_SUPPLEMENTARY_VALIDATION.md`。S1 的 6 次 GET 数字仅指原 S1 阶段，不含补充验证。
