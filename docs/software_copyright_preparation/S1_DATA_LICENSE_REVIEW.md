## 使用场景区分

**A 软件著作权申请**：CarbonAI 自研程序、文档的权属和实际开发过程由申请人核查；软件登记本身不会使第三方 API、遥感数据、图像和商标成为 CarbonAI 自有资产。

**B 数据/API 使用**：§3.1–3.4 对符合条件的非商业学术展示、使用及再分发提供默认许可，**不以另行书面授权作为一概前提**；但实际运营需确属非商业、符合减排目的、清晰署名，并对再分发传递相同条件。本轮**无法确认 CarbonAI 的运营事实及网站条款**。在确认前可保留受控研究核验；公开展示、下载和缓存应待这些事实与集成方式核实后决定。

**待确认清单**：网站是否完全免费；是否有付费功能、商业客户或广告；是否确为高校研究和非商业演示；未来是否把观测数据用于收费服务；网站能否提供清晰署名与数据使用条件；网站用户能否导出/复用数据；API 注册和端点配额；样例/缓存能否进入 Git 或申请材料；中国访问及跨境使用的适用合规。仓库 `README.md` 称“已上线运营”，但不证明收费或不收费。需负责人确认运营事实，存在争议再向权利方或专业人士核实。S2 公开接入当前不通过许可门。
