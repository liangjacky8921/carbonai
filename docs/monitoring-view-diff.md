# CarbonAI V6.0 · 三类用户实时监测视图差异清单

> 背景：碳源实时监测模块需要面向 **企业运维、老板决策、商业运营户** 三类角色做差异化视图。本清单列出每类角色独立的指标、粒度和操作，避免信息过载或功能重叠。

---

## 一、角色定义

| 角色 | 典型用户 | 核心诉求 | 设备偏好 |
|---|---|---|---|
| **企业运维** | 环安/能源管理岗、EHS 专员、厂站技术负责人 | 多排放源总览、合规状态、问题定位 | 桌面端（大屏优先） |
| **老板决策** | 董事长/CEO、投资人、董事会成员 | 极简 KPI 大屏、手机随时看、趋势稳定/异常 | 手机端 + 桌面大屏 |
| **商业运营户** | 酒店/餐饮/商超店长、连锁门店管理员 | 单店简版、节能建议、不超预算 | 手机端为主 |

---

## 二、企业运维视图（桌面端）

### 2.1 必看指标
| 指标 | 粒度 | 刷新频率 | 目的 |
|---|---|---|---|
| 全厂总排放速率 | tCO₂e/h | 5s | 实时掌握全厂排放负荷 |
| 各子源（锅炉/电力/工艺/废水）排放占比 | tCO₂e/h + % | 5s | 定位高排放子源 |
| 合规状态 | 是否超国标阈值 | 1min | 确保合规，避免罚款 |
| 超阈值告警列表 | 点位 ID + 超标时长 | 5s | 第一时间派员核查 |
| 近 24h 趋势 | 每 5min 聚合 | 1min | 判断是否持续恶化 |
| 日/月累计排放 | 按 Scope 1/2/3 分类 | 每小时 | 月度预算执行跟踪 |

### 2.2 操作权限
- ✅ 查看全部点位详细数据
- ✅ 手动触发校准/清零
- ✅ 配置告警阈值（CONFIG 可调）
- ✅ 导出原始数据 CSV
- ✅ 生成合规报告草稿

### 2.3 界面布局
```
┌─────────────────────────────────────────┐
│ 全厂 KPI 条：总排放 · 合规状态 · 今日累计 │
├──────────────┬──────────────────────────┤
│ GIS 热力地图 │ 子源柱状图（实时）        │
│ （点位 +     │ 告警列表（Top 10）        │
│  热力叠加）  │ 24h 趋势折线              │
└──────────────┴──────────────────────────┘
```

## 三、老板决策视图（移动端 + 桌面极简）

### 3.1 必看指标（≤ 6 个 KPI）
| 指标 | 粒度 | 刷新频率 | 目的 |
|---|---|---|---|
| 今日累计排放 | tCO₂e | 1min | 一眼看量级 |
| 对比基准（同比/环比） | % | 1min | 减排有没有起效 |
| 绿电占比 | % | 5min | ESG 叙事素材 |
| 超阈值点位数量 | 个数 | 5s | 有没有紧急情况 |
| 预算执行进度 | % | 1h | 会不会超预算 |
| 减排量 vs SBTi 目标 | 差值 | 1d | 科学碳目标跟进 |

### 3.2 操作权限
- ✅ 只读浏览（禁止修改任何配置）
- ✅ 一键生成高管简报（3 行总结 + KPI 截图）
- ❌ 不显示任何技术参数/原始数据
- ❌ 不允许配置阈值/告警规则

### 3.3 界面布局（手机竖屏优先）
```
┌─────────────────┐
│ 今日排放 📊      │
│ ┌─────────────┐ │
│ │  12.4 tCO₂e  │ │  ← 大号数字
│ │  ↓ 5.2% YoY │ │
│ └─────────────┘ │
├─────────────────┤
│ 绿电占比 72%    │ ← 进度条
│ 预算 68% · 正常 │
├─────────────────┤
│ 🚨 2 个点位超阈值│ ← 红色高亮，点进去看详情
├─────────────────┤
│ 减排进度 vs 目标 │ ← 180 天 SBTi 折线
└─────────────────┘
```

## 四、商业运营户视图（手机端 · 单店简版）

### 4.1 必看指标（≤ 4 个 KPI）
| 指标 | 粒度 | 刷新频率 | 目的 |
|---|---|---|---|
| 本店今日排放 | kgCO₂e | 1min | 和老板看的不同量级（kg vs t） |
| 对比周边门店均值 | % | 1h | 知道自己排多了还是排少了 |
| 能耗（电+水）趋势 | kWh / m³ | 5min | 日常运营参考 |
| 节能建议条数 | 数量 | 1d | AI 自动生成，点进去看详情 |

### 4.2 操作权限
- ✅ 查看本店数据
- ✅ 接收 AI 节能建议推送
- ❌ 不显示企业级 Scope 1/2/3 分类
- ❌ 不允许配置阈值（由企业总部统一管控）
- ❌ 不显示合规状态（合规由总部负责）

### 4.3 节能建议示例（AI Advisor 生成）
```
💡 节能建议 · 预期年减排 1.2 tCO₂e
┌──────────────────────────────┐
│ 后厨冰箱温度从 4℃ 调至 5℃      │
│ （行业最佳实践，食材新鲜度不变） │
│ 节省 ≈ 15 kWh/天 · ¥1.2k/年   │
│                              │
│ [采纳] [忽略] [稍后再说]       │
└──────────────────────────────┘
```

## 五、三类视图的字段/组件差异矩阵

| 功能模块 | 企业运维 | 老板决策 | 商业运营户 |
|---|---|---|---|
| GIS 热力地图 | ✅ 全功能（点+热） | ❌ 不显示 | ❌ 不显示 |
| 子源占比柱状图 | ✅ 显示 | ❌ 不显示 | ❌ 不显示 |
| 24h 趋势折线 | ✅ 显示（5min 粒度） | ⚠️ 只显示周/月级别 | ❌ 不显示 |
| Scope 1/2/3 分类 | ✅ 显示 | ⚠️ 只显示 Scope 2（绿电占比） | ❌ 不显示 |
| 合规状态检查 | ✅ 核心功能 | ❌ 不显示 | ❌ 不显示 |
| 告警列表（详细） | ✅ Top 10 + 全部历史 | ⚠️ 只显示数量 | ❌ 不显示 |
| 阈值配置 | ✅ 可编辑 | ❌ 只读/隐藏 | ❌ 隐藏 |
| 导出原始数据 | ✅ CSV/Excel | ❌ 隐藏 | ❌ 隐藏 |
| SBTi 目标对比 | ⚠️ 可选模块 | ✅ 核心展示 | ❌ 隐藏 |
| 节能 AI 建议 | ❌ 不显示 | ❌ 不显示 | ✅ 核心功能 |
| 单位 | tCO₂e / kgCO₂e | tCO₂e（只显示量级） | kgCO₂e |
| 刷新频率 | 5s 实时 | 1-5min | 1-5min |

## 六、CONFIG 可调参数（三类视图共用同一配置源）

```yaml
monitoring_view_config:
  # 老板视图聚合粒度（老板和商业户不看 5s 明细，走聚合值）
  boss_aggregation_interval_minutes: 10

  # 商业户是否附加节能建议字段
  business_show_savings_tip: true

  # 企业运维最大告警历史条数
  enterprise_max_alert_history: 500

  # 是否允许企业用户自定义阈值（false=读 config 默认值）
  enterprise_allow_custom_thresholds: true
```
