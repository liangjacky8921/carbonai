# CarbonAI V5.2 — 云服务器部署指南（阿里云 / 腾讯云学生机 + Nginx）

> 目标：以最低成本实现 7×24 小时在线访问，使平台成为**已上线运营的 Web 平台**。
> 适用：阿里云飞天加速计划学生机（2核2G 起）、腾讯云学生优惠（2核2G/4G）或任意 1核1G 以上 Linux 云服务器。

## 1. 服务器初始化（Ubuntu 22.04 为例）

```bash
# SSH 登录
ssh root@<服务器公网IP>

# 基础环境
apt update && apt upgrade -y
apt install -y nginx git curl
curl -fsSL https://deb.nodesource.com/setup_20.x | bash - && apt install -y nodejs
apt install -y python3 python3-pip python3-venv

# 防火墙（放开 SSH/HTTP/HTTPS）
ufw allow 22,80,443/tcp && ufw enable
```

## 2. 拉取代码

```bash
mkdir -p /opt/carbonai && cd /opt/carbonai
git clone https://github.com/<你的用户名>/carbonai.git .
```

## 3. 构建前端

```bash
cd /opt/carbonai/frontend
npm install --registry=https://registry.npmmirror.com
npm run build:fast     # 产出 dist/ 静态文件
```

## 4. 启动后端（FastAPI）

```bash
cd /opt/carbonai/backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple

# 测试运行
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

### systemd 常驻服务（7×24）

```bash
cat > /etc/systemd/system/carbonai-api.service <<'EOF'
[Unit]
Description=CarbonAI FastAPI Backend
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/carbonai/backend
ExecStart=/opt/carbonai/backend/.venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 2
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable --now carbonai-api
systemctl status carbonai-api
```

## 5. Nginx 反向代理

```bash
cat > /etc/nginx/sites-available/carbonai <<'EOF'
server {
    listen 80;
    server_name _;   # 有域名改为 carbontool.cn

    gzip on;
    gzip_types text/css application/javascript application/json image/svg+xml;

    # 前端静态文件
    root /opt/carbonai/frontend/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;   # SPA 路由回退
    }

    # 静态资源长缓存
    location /assets/ {
        expires 30d;
        add_header Cache-Control "public, immutable";
    }

    # 示例数据文件
    location /sample-data/ {
        expires 1d;
    }

    # API 反向代理到 FastAPI
    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_read_timeout 60s;
    }
}
EOF

ln -sf /etc/nginx/sites-available/carbonai /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t && systemctl reload nginx
```

## 6. 访问验证

```bash
curl http://127.0.0.1/api/health
# {"status":"ok","service":"carbonai-api","version":"5.2.0"}
```

浏览器访问 `http://<服务器IP>` → CarbonAI 登录页 → 注册/登录 → 数据大屏。

## 7. 绑定域名 + HTTPS（可选但推荐）

```bash
apt install -y certbot python3-certbot-nginx
# 先把域名 A 记录解析到服务器 IP，且 Nginx server_name 改为 carbontool.cn
certbot --nginx -d carbontool.cn
# 自动续期已内置，验证：
systemctl list-timers | grep certbot
```

## 8. 2G 内存优化（学生机必看）

```bash
# 1) 前端构建在本地电脑完成，只上传 dist/（服务器不跑 npm build）
# 2) 限制 uvicorn workers=1（2核2G）或 2（2核4G）
# 3) 加 2G swap：
fallocate -l 2G /swapfile && chmod 600 /swapfile
mkswap /swapfile && swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```

## 9. 更新发布流程

```bash
cd /opt/carbonai
git pull origin main
cd frontend && npm run build:fast     # 或本地构建后 rsync dist/
cd ../backend && source .venv/bin/activate && pip install -r requirements.txt
sudo systemctl restart carbonai-api && sudo nginx -s reload
```

## 10. 常见问题

| 现象 | 处理 |
|---|---|
| 页面空白 404 | Nginx 未配置 `try_files ... /index.html` |
| API 502 | `systemctl status carbonai-api` 查看后端日志 `journalctl -u carbonai-api -f` |
| 前端显示「前端独立模式」 | 后端未启动或 `/api/health` 不通，功能仍可用（Mock 模式） |
| 内存不足 OOM | 见第 8 节 swap；uvicorn workers 降为 1 |
| 域名证书续期失败 | `certbot renew --dry-run` 排查 80 端口可达性 |
